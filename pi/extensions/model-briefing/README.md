# Model briefing

Injects initial context for delegating parents: up to 100 native run summaries from default Pi session artifact directories, plus exact Terminal-Bench model/thinking rows. Custom roots and mixed-model runs are skipped. No transcripts read or local data uploaded. Costs are estimates, not subscription bills; exits aren't quality scores. No routing changes.

Daily cache: `<agentDir>/model-briefing/terminal-bench.json`. Fetch timeout: 4s; offline/failure uses labeled stale/unknown data. Setup links it; restart or `/reload`. Reinjects after rewind/compaction only when absent from active context.
